# Hojokin Compass アクセス解析・成長指標設計

2026-10-19。**広告費0円、個人情報非保有、登録不要**を守り、集客と収益化の判断に使う。

## Phase 1: Google Search Console（無料）
- 対象プロパティ: `https://od-projects-jp.github.io/hojokin-compass/` （URLプレフィックス）。
- 所有権確認: Search Consoleで発行されたHTMLファイルをサイトの公開ルートに置く方法を第一候補とする。**検証用の実ファイル名・内容は所有者が発行してから追加する**。トークンを推測・生成しない。
- 登録するサイトマップ: `https://od-projects-jp.github.io/hojokin-compass/sitemap.xml`。
- 週次で検索クリック、検索表示、CTR、平均掲載順位、流入ページ、検索クエリ、デバイスを確認する。Search Consoleの検索データには遅延・匿名化・閾値があるため、完全な全アクセス数と見なさない。
- GitHub Pagesの既存の公開URLは確認可能。独自ドメインを導入したら所有権確認と正規URL・サイトマップを再検討する。

## Phase 2: サイト内の行動計測（要選定）
Search Consoleでは、**総PV、検索フォーム利用、フィルタ選択、結果表示、公式サイトへのクリック、提携先へのクリック**はわからない。
次の候補をプライバシー・費用・利用規約で比較する：
1. プライバシー重視のアクセス解析サービス（無料枠があり、同意要件とデータの処理内容を確認できる場合）。
2. 自前の匿名集計エンドポイント。ただし静的サイトから外部サーバーへイベント送信する必要があり、運用・安全・費用面で初期は優先しない。
3. GA4。無料だが外部タグ・Cookie等の扱い、プライバシー表示・同意要件・IP等の処理の検討が必要。**無断で設置しない**。

検索語、所在地、検索条件、お気に入り、個人識別子を生データとして外部へ送らない。外部リンクに検索語や個人情報を付加しない。

## 経営KPI（毎週）
| 段階 | 指標 | 情報源 | 備考 |
|---|---|---|---|
| 認知 | 検索表示回数 | Search Console | 自然検索 |
| 集客 | 検索クリック数 | Search Console | サイト全流入ではない |
| 改善 | CTR・平均順位 | Search Console | ページ・クエリ別 |
| コンテンツ | 掲載確認済み制度数、地域カバー率 | 公開JSON | 公開範囲の実績 |
| 品質 | リンク監査の問題数、更新日、収集エラー数 | GitHub Actions | 公式データの健全性 |
| 利用 | ページビュー、検索実行、制度詳細・公式リンククリック | 将来の解析サービス | 現時点では未計測 |
| 収益 | 提携先への送客、承認成果、確定報酬 | 提携先管理画面 | 提携契約後 |

## 判断の基準
- まずSearch Consoleを稼働させ、検索流入の実数と伸びを見える化する。
- 制度の追加と検索品質を優先し、実測データから需要のあるテーマ・地域を決める。
- 有料広告の予算は0円。アクセス数が少ない時点で広告タグを大量導入しない。
- 収益化前に、提携先のクリック・成果を追える**個人情報を持たない集計方法**を決める。
- 指標が取得できていない場合は0と表記せず「未計測」とする。

## 所有者の操作が必要な事項
1. Googleアカウントで [Search Console](https://search.google.com/search-console/) を開く。
2. URLプレフィックスとして `https://od-projects-jp.github.io/hojokin-compass/` を追加。
3. HTMLファイル確認を選択して、Googleが発行する検証ファイルを取得。
4. 検証ファイルを公開ルートに配置し、Search Consoleの「確認」を押す。
5. `sitemap.xml` を送信。数日後から検索パフォーマンスのデータを確認する。

**注意**: GitHub Pagesがサブパス配信のため、検証ファイル方式がSearch Consoleの画面で利用可能かを確認する。所有権確認方法が制限される場合はHTMLメタタグ方式を利用する。確認トークンは実際に発行された値だけを使う。
