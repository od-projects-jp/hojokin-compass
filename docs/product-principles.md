# Hojokin Compass — 事業・開発方針（2026-10-19決定）

本書は、今後の開発、UI/UX、データ管理、収益化に適用する**決定済みの前提条件**です。既存の仕様や提案と矛盾する場合は本方針を優先します。

## 1. 利用者と課金
- 会員登録を必須にしない。初期段階では**会員機能自体を実装しない**。
- **有料会員制を導入しない**。検索・閲覧・お気に入り等は完全無料を基本とする。
- 会員登録、ログイン、パスワード再設定、会員DB、決済機能を初期開発の対象外とする。

## 2. 個人情報・プライバシー
- **個人情報は原則取得・保有しない**。氏名、メールアドレス、電話番号、住所、本人識別情報等の入力・保存を要求しない。
- 検索条件とお気に入りは、可能な範囲で利用者の**ブラウザ内**（localStorage等）に保存する。サーバー同期はしない。
- ブラウザ保存データの消去方法を案内し、共用端末では他の利用者に閲覧され得る点に配慮する。
- 外部解析タグ、広告タグ、アクセスログ、Cookie、第三者へのデータ送信は導入前に必要性・取得情報・同意や告知の要否を検証し、最小限にする。
- GitHub Pagesや外部サービス側の技術的アクセスログ等は本サイトから完全に制御できない。**サイト運営者が独自に利用者データを集約しない**ことと、外部サービスによる処理を区別して説明する。

## 3. 収益化
- 収益化は**外部送客・アフィリエイトを中心**とする。
- Hojokin側でリード情報を受領・保管・転送しない。提携先のサイトに直接遷移し、個人情報の入力が必要な場合は提携先が直接取得する。
- 広告・アフィリエイトの表示は分かりやすく区別し、検索順位やおすすめ結果への影響がある場合は明示する。
- トラッキング用パラメータ、外部計測、成果計測に伴う情報取得の範囲は導入前に確認する。

## 4. セキュリティと運用
- 原則として静的サイト・公開データを中心に構築し、認証基盤や個人情報DBを持たない。
- 収集データは公式ソース、確認日、更新状態を管理し、未確認の候補を確認済み制度として公開しない。
- 利用者情報を必要とする通知メールや会員限定機能は実装しない。
- 新機能のレビューでは「個人情報取得の有無」「外部送信の有無」「運用負荷」「利用者の無料アクセス」を必須確認項目とする。

## 5. 開発時の受け入れ基準
1. 会員登録なしで検索・閲覧できる。
2. 無料で主要機能を使える。
3. 検索条件・お気に入りはサーバー送信せずブラウザ内で保持する。
4. サイト運営者のDBに利用者の個人情報を保存しない。
5. 外部送客は直接リンクを基本とし、広告・提携表示を明確にする。
6. 新しい解析・広告・外部SDKの導入は、データ取得範囲を確認してから判断する。

**変更管理**：上記の方針を変更する場合は、事業上の理由とプライバシー・セキュリティへの影響を整理し、明示的に再決定する。
