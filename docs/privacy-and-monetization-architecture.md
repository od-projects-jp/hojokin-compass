# Hojokin Compass — プライバシー・収益化の実装基準

2026-10-19決定の [事業・開発方針](product-principles.md) をコード上で守るためのチェックリストです。

## 現在の構成
- 静的HTMLと公式データのJSONを配信。会員DB、認証、決済、通知メールは設けない。
- 検索条件・お気に入りは `privacy-storage.js` を通してブラウザの `localStorage` に保存。サーバーへ同期しない。
- 保存が無効な環境でも検索とページ内のお気に入りは利用可能（再訪時の復元は保証しない）。
- ブラウザ内のデータ削除機能は個人・法人検索とプライバシー説明ページに設置。**サイトと同一オリジンの他のデータは削除しない**。
- 公式制度のデータ取得はGitHub Actionsが公的データソースから行い、個々の訪問者の検索条件を収集しない。

## 今後の機能追加時に必須の確認
1. 収集するデータと保存先：利用者個人を特定・追跡する項目がないか。
2. 通信先：外部JavaScript、解析、広告タグ、埋め込みコンテンツが利用者の情報を送信しないか。
3. 利用者の権利：無料・登録不要の検索体験が維持されているか。
4. 送客：提携先のURLへ直接リンクし、Hojokinが問い合わせフォームやリード情報を受け取らないか。
5. 広告表記：広告・アフィリエイトであることを分かる位置に明示するか。
6. 成果計測：提携先のトラッキングやURLパラメータによるデータ処理を導入前に審査するか。
7. 保存・削除：利用者がブラウザ内の保存内容を簡単に削除できるか。
8. 保守：公式データの更新、リンク監査、テストで継続運用できるか。

## 収益化実装の順序
- 第1段階：無料検索と制度情報の充実。送客先は公式情報への直接リンク。
- 第2段階：ユーザー価値に沿う提携候補を選定。広告主との契約・法的表記・プライバシー影響を確認。
- 第3段階：提携リンクを明示して導入。外部フォームは提携先が直接提供し、Hojokin側では個人情報を受け取らない。
- 有料会員制、メールアドレス取得を前提とする通知、ログイン機能は導入しない。

## 自動チェックの限界
`tests/privacy-guardrails.test.js` は静的HTMLにおける外部スクリプト、追跡コードの典型例、メール・パスワード入力欄を検出します。**これだけで個人情報保護やセキュリティが完全に保証されるわけではありません**。ホスティング事業者のログや外部リンク先での処理は別途確認します。
