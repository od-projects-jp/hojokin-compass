# 広告費ゼロの成長・収益化ロードマップ

2026-10-19 策定。**有料集客費0円、会員登録不要、利用者個人情報を保持しない**方針を維持する。

## 成長戦略
- まず検索体験と確認済みの制度情報を改善。掲載件数だけを目的に未確認情報を公開しない。
- SEO: 独自の利用ガイド、制度の対象条件、公式情報確認日、地域別の掲載状況をわかりやすく表示。低品質な自動生成ページを量産しない。
- Google Search Consoleは無料で利用できるが、所有権確認は運営者が行う。検索流入と掲載状況を確認する。**サイト側に利用者追跡タグを入れない。**
- 公式情報の引用は必要最小限にし、独自の要約・公式ページへの導線を提供する。
- 広告費をかけず、自然検索、関連する公開コミュニティでの有益な紹介、公式データの継続更新による流入を目指す。スパム投稿・リンク購入はしない。

## 収益化の優先順位
1. **事業者向けの関連サービスへの成果報酬型送客**。例：補助金申請に関する専門家相談、会計ソフト、業務効率化ツール。ただし契約・資格要件・広告審査・広告表示・ユーザー適合性を確認するまでリンクを掲載しない。
2. 個人向けは、制度利用に必要なサービスが実際にある場合のみ提携候補を検討。公的支援制度そのものに申請手数料がかかるかのような誤認を避ける。
3. 広告ネットワークは初期導入しない。第三者スクリプト・追跡・画面品質への影響が大きいため。
4. 有料会員、利用者データ販売、メールリスト取得、Hojokin上での問い合わせ収集は行わない。

## リリース・収益化ゲート
- **公開品質**: 無料検索が正常に動く、公式リンクと対象要件を示す、掲載範囲の限界を明示する、スマートフォンで利用可能、主要テストが成功する。
- **自然流入**: Search Consoleで検索流入・インデックス状況を確認。実数を把握するまで成果やPVを推定値で断定しない。
- **提携開始**: 運営主体・広告表記・プライバシー・送客先の契約条件を確認し、訪問者に必要な提携サービスのみ選ぶ。報酬がなくても公式情報への導線を維持する。
- **検証**: 提携先ダッシュボードでクリック・成果・承認・収益を確認。個人単位のログはサイトに保存しない。

## 費用・リスク
- 有料広告費の上限：**0円**。
- ドメイン、ホスティング、API、外部SaaSは新たな支出を承認なく増やさない。
- アフィリエイトASPの例としてA8.netはメディア登録・利用が無料と案内している。ただし個別案件の提携承認、成果条件、規約は別途確認する。運営者登録には別途アカウント情報や振込先が必要であり、Hojokin訪問者の登録とは異なる。
- 利益相反が生じうる取引先や業務領域は、契約・所属先の兼業ルールを確認するまで提携しない。

## 次の実装順
1. 現在の公式ソース収集の失敗を修復し、自治体ごとのデータソースを増やす。
2. 地域別の制度充実と正確性監査。
3. 検索流入に資する独自の説明ページを、利用価値があるテーマから作る。
4. 運営者の承認が必要なASP登録・提携契約・法的表示を整え、適切なタイミングで広告を開始する。
